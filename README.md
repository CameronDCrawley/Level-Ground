## Level Ground Mixed Martial Arts Website
A complete community-driven web platform for Level Ground (LG), an urban youth initiative where young athletes cultivate grit and resilience through Mixed Martial Arts, student trainer certification, and college access programs.

## Live Demo
Netlify Deployment: https://levelgrounds2.netlify.app

## Features
Header & Navigation: Clean navigation links for Classes and Hire Us, paired with the official Level Ground logo and a prominent Donate action button.

Hero Section: Highlights Level Ground's core mission—where urban youth learn discipline and resilience on and off the mat.

Mission & Impact ("WHY"): Dedicated breakdown explaining how MMA training fosters confidence, strength, and community support.

## How It Works
Structure & Layout: Formatted using modern semantic HTML5.

Styling Integration: Linked to css/style.css for responsive layouts, media query adjustments, and custom grid/flex containers.

Asset Handling: Embeds localized images for gym facilities, sparring training, logos, and social media icons.
